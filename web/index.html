本工具测试当前网络到甲骨文云 Object Storage 区域入口的 TCP 建连速度，仅用于线路对比，不代表具体云服务器的完整业务性能。

测试节点管理

使用提示：只测试你有权访问的服务器。甲骨文默认节点可以停用但不能删除；自定义节点最多 100 个。要把自定义节点搬到另一台电脑：先点“复制全部自定义节点”，再到那台电脑的“批量导入”里粘贴即可。
